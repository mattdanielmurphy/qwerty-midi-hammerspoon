# Project: qwerty-midi-hammerspoon R1-R7 Suite

## Architecture
- **Monorepo Structure**: Bun workspace (`packages/*`) with legacy/active QWERTY Lua source in `src/` and offline webview HUD in `src/web/index.html` (synced to `src/ui_html.lua`).
- **Audio & MIDI Engine**:
  - `src/midi.lua`: CoreMIDI virtual endpoint communication, CC / Note messages, active voice ledger.
  - `packages/music-engine/quantizer.lua`: Input quantizer with microsecond precision, anticipation, catch-up, and strength scaling.
  - `src/arpeggiator.lua`: 4 independent track arpeggiators with clock scheduling, velocity contours, gate ratios, and microtiming.
  - `src/controls.lua`: Key dispatch, modifier layers, volume adjustments, tap tempo, track routing.
  - `src/config.lua`: State defaults, settings persistence (`hs.settings`).
  - `src/init.lua`: Lifecycle management, event taps, watchdog timers (strictly active only when armed).
- **HUD & UI Overlay**:
  - `src/hud.lua`: Coalesced 30fps payload generation, key state calculation, modifier mapping.
  - `src/web/index.html`: WebKit UI, CSS Grid / Flexbox layout, 58px keypads, zero layout shift bounds.
  - `src/ui_html.lua`: Embedded HTML string generated by `bin/hs-bundler`.
- **Build & Bundle Pipeline**:
  - `bin/hs-bundler`: Multi-module bundler compiling `src/` into single `qwerty_midi.lua`.
  - `bin/bundle_and_reload.sh`: Trigger script with `luac -p qwerty_midi.lua` validation.

## Interface Contracts
### `packages/music-engine/quantizer.lua` ↔ `src/config.lua` & `src/hud.lua`
- `quantizer.calculateDelay(bpm, mode, amount)`:
  - `amount`: number in [0, 100], default 90.
  - Return: delayed seconds scaled by `(amount / 100)`.
- `quantizer.setQuantizeAmount(amount)`: sets runtime percentage.
- `state.inputQuantizeAmount`: persisted in `hs.settings` as `qwertyMidi_inputQuantizeAmount`.

### `src/midi.lua` ↔ `src/init.lua` (Watchdog Contract)
- `midi.getActiveVoices()`: returns table of sounding notes `{ [voiceKey] = { note = n, ch = c, startTime = t, track = trk } }`.
- `midi.checkOrphanedVoices(maxAgeSeconds)`: releases notes sounding longer than threshold, calls `sendNoteOff`.
- Invariant: Watchdog timer runs ONLY when `state.midiActive == true`.

### `src/arpeggiator.lua` ↔ `src/controls.lua` (Tap Tempo Contract)
- `arpeggiator.tapTempo()`:
  - Records timestamp of tap (`hs.timer.secondsSinceEpoch()`).
  - Resets tap history if gap > 2.0 seconds.
  - Computes rolling average intervals ($N = 4..8$) and derives BPM clamped to [30, 300].
  - Calls `arpeggiator.applyBpmChange(newBpm)` and updates HUD.

### `src/controls.lua` ↔ `src/hud.lua` (Track Volume Keys)
- Dedicated actions: `trkVolUp1..4` and `trkVolDown1..4`.
- Repeat timer uses debounced `saveSettings()` (300ms trailing timer) instead of blocking synchronous writes on every 80ms tick.

### `src/web/index.html` ↔ `src/hud.lua` (Key Overlay & ZLS)
- `.key-pad .key-note`: fixed height 20px, `white-space: pre-line`, `overflow: hidden`, `font-variant-numeric: tabular-nums`.
- Key labels receive active quantity formatted as 2nd line: `"{Action}\n{Value}"`.
- Unmapped keys in Cmd layer receive blank/subdued indicator, eliminating wall-to-wall "Pass Through" collisions.

## Code Layout
- `src/config.lua`: Configuration keys, defaults, persistence.
- `src/controls.lua`: Input key mappings, repeat timers, volume dispatch.
- `src/arpeggiator.lua`: Arp engine, tempo, velocity contours, human feel.
- `src/midi.lua`: MIDI send/receive, voice ledger, orphan clearing.
- `src/hud.lua`: HUD data preparation, shortcut definitions, dynamic note labels.
- `src/init.lua`: Module lifecycle, event taps, watchdog timers.
- `packages/music-engine/quantizer.lua`: Timing math, queue management.
- `src/web/index.html`: Webview HUD HTML, CSS, JS.
- `src/ui_html.lua`: Bundled webview content.
- `bin/hs-bundler`: Lua module bundler.
- `bin/bundle_and_reload.sh`: Bundle script with `luac -p` validation.
- `tests/`: Bun test suites.
