# Shift Key Sustain and Arpeggiator Bypass on Note Taps

If a note is tapped when shift is held, it should do the opposite of the current sustain/arp mode:
- If arp mode is on, holding shift will make it trigger as a normal note, bypassing the arp.
- If sustain is on, holding shift will bypass the sustain and have it trigger as a normal note.
- This bypass works on either keyboard row.
