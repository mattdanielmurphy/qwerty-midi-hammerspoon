# Correlated Key Pair Styling

- Group and color related control key pairs (e.g. J/K Transpose, H/L Root, G/; Mode, D/F Octave, 3/4 Dir, 5/6 Rate, 7/8 Gate, -/= BPM) so correlated actions share distinct, understated color accents fitting the dark theme.
- Ensure control keys look integrated and balanced rather than overly prominent relative to note keys.
